# 🛒 Offline AI Sales Decision Support System (SDSS)

An on-device, privacy-preserving AI decision-support prototype designed for retail sales specialists. It dynamically generates context-aware sales pitches, risk indices, and bundle discount calculations without relying on cloud APIs.

---

## 🌟 Key Features

* **100% On-Device & Offline AI:** Powered by Ollama (`qwen2.5:3b`) for zero cloud costs and full compliance with GDPR / KVKK data privacy regulations.
* **Dynamic Persuasion Pitching:** Generates tailored, single-sentence sales scripts based on the customer's risk profile and product margins.
* **Smart Bundle & Discount Engine:** Automatically calculates cross-selling options (warranties, maintenance, lifetime software) and side-by-side discount comparisons.
* **Advisor Coaching & Churn Index:** Classifies products into price/risk segments to guide store advisors toward optimal warranty closures.
* **Alternative Recommendations:** Scans the internal catalog to suggest budget-friendly or higher-segment alternatives in real time.

---

## 🚀 Tech Stack

* **Language:** Python 3.10+
* **Local LLM Engine:** Ollama (`qwen2.5:3b`)
* **Architecture:** Edge-AI / On-Device Logic Engine
